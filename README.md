# coolify-demo

Global stateless deployment demo for OpsKit and Coolify Cloud

## Getting Started

```bash
pnpm install
pnpm run dev
```


## Validation

```bash
pnpm run agent -- status
pnpm run verify
pnpm run test:e2e
```
